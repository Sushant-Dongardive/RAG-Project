Project Documentation

Agentic RAG Platform

Agentic RAG Platform for Academic & Enterprise Intelligence.

Primary Objective

Build an Agentic Retrieval-Augmented Generation system that retrieves relevant knowledge from documents, generates evidence-based answers and verifies the generated information.

Four-Agent Architecture

Planner Agent Understands the query and selects a retrieval strategy.
Retriever Agent Retrieves evidence using vector search, BM25 and RRF.
Synthesizer Agent Generates an answer using retrieved evidence.
Fact-Checker Agent Verifies generated claims against the evidence.

Current Technology Stack

Python FastAPI FAISS BM25 RRF Sentence Transformers Ollama LLM
